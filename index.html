⑤ Personal Context → My AI

P2 Minimal MVP
Evidence가 2회 이상 누적된 확정 객체에서 Personal Context 후보를 제안합니다.
아직 확인된 Personal Context가 없습니다.
Evidence는 “무슨 일이 있었는가”, Personal Context는 “이 사용자에게 무엇을 의미하는가”를 구분합니다. AI는 Context 후보를 제안하고, 사용자가 확인한 것만 Personal Context가 됩니다.

⑥ Context-Driven AI Behavior

P3 · Rule Engine
Personal Context가 My AI의 다음 판단을 실제로 바꾸는지 검증합니다. 현재는 교체 가능한 Simple Rule Engine을 사용합니다.
현재 P3 엔진
simple-0.1
계약: Personal Context + Battle History + 후보 → 다음 판단 + 판단 근거
Context가 없는 경우 기존 Battle과 동일하게 동작하고, Context가 있는 경우 과거에 놓친 개인 객체를 우선 선택합니다. 이후 Simple Rule Engine만 Huge Rule Engine으로 교체할 수 있습니다.
교육용 MVP입니다. 카메라/위치 권한이 필요하며, 현재 구현은 브라우저에서 모델 추론을 수행하고 Evidence를 localStorage에 저장합니다. Physical Object Identity는 현재 카메라 이미지의 간단한 시각적 fingerprint를 이용한 MVP 수준의 중복 판정입니다. 실제 배포 전에는 HTTPS, 개인정보 보호, 미성년자 동의/보호 절차, 모델/라이브러리 라이선스를 별도 검토해야 합니다.
