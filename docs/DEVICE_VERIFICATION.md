## 2. 사용자 확인 실기기 테스트

**날짜:** 2026-10-18  
**환경:** 스마트폰 (기기 모델, OS, 브라우저 버전은 미기록)  
**상태:** 사용자가 전체 게임 테스트를 완료했다고 확인함.

| 항목 | 기록 |
|---|---|
| 게임 모듈 선택 및 전환 | 사용자 확인: 테스트 완료 |
| 가위바위보 | 사용자 확인: 테스트 완료 |
| 홀짝 | 사용자 확인: 테스트 완료 |
| 주사위 | 사용자 확인: 테스트 완료 |
| 전체 게임 테스트 결과 | 사용자 보고: 정상 |
| 개별 테스트 케이스별 로그 | 별도 기록 없음 |

이 기록은 사용자의 직접 실기기 테스트 보고에 근거합니다. 개별 게임별 결과/화면 캡처, 기기·브라우저 버전은 보관되어 있지 않습니다.

## 3. 기존 스마트폰 스모크 테스트 기록

사용자는 앞선 점검에서 스마트폰 기본 기능 체크리스트가 정상이라고 보고했습니다. 여기에는 카메라/영상, 객체 관측 및 Evidence, 객체 3개 수집, 게임 전환, 결과 및 Monster Collection, 새로고침 후 데이터 유지, GPS/P3 확인이 포함됩니다. PC 카메라 테스트는 확인되지 않았습니다.

## 4. 알려진 제한 및 출시 전 점검

- 물리 객체 재관측은 같은 AI 라벨 + 시각 유사도 + 최근 20분 이내 + 15m 이내 조건에 의존합니다. 실제 환경에서의 도달 가능성/정확도는 별도 검증 대상입니다.
- GPS 원본 좌표가 `arq_gps` 및 `evidence.location.gps`를 통해 localStorage에 저장됩니다. 현재 MVP 범위에서는 유지하되, 다중 사용자/서버 동기화 전 개인정보·보안 설계를 재검토합니다.
- 학생 제작 JavaScript는 신뢰된 페이지 스크립트로 실행됩니다. 샌드박싱 없이 공개 배포하지 않습니다.
- TensorFlow.js 및 COCO-SSD 외부 CDN 의존성의 라이선스와 공급망 보안을 상업/교육 배포 전에 확인합니다.
- PC 카메라 동작은 아직 검증되지 않았습니다.
